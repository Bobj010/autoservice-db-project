# Проект: База данных и информационная система автосервиса
**Информационная система «АвтоСервис-Экспресс» (ООО «АвтоМастер-Сервис»)**  
*СУБД: SQLite 3 | Версия 2 (доработанная по замечаниям преподавателя с очного разбора)*

---

## 📁 Структура проекта

### 1. Основные файлы для сдачи (в корневой папке):
* **`Анализ_Автосервис.docx`** — Полный аналитический отчет по проектированию ИС и базы данных:
  - **Раздел 1**: Краткая характеристика автосервиса ООО «АвтоМастер-Сервис», направления деятельности, **графическая схема организационной структуры**, цели автоматизации.
  - **Раздел 2**: Бизнес-процессы предприятия (классификация на операционные, управленческие, обеспечивающие; регламент ТО; **матрица ответственности RACI**; **модели процессов IDEF0 и DFD**).
  - **Раздел 3**: Информационная система «АвтоСервис-Экспресс» (6 модулей, СУБД SQLite 3, **схема архитектуры ИС**, контур администрирования, безопасность по **ФЗ-152**, резервное копирование).
  - **Раздел 4**: Сущности и атрибуты (детальная спецификация 8 таблиц, **матрица соответствия ключей PK <-> FK**, обоснование 3НФ, **назначение B-Tree индексов**).
  - **Раздел 5**: Пользователи и запросы к БД (4 роли, 11 типовых запросов с JOIN/агрегацией + **Спецзадание преподавателя: Запрос №12 БЕЗ JOIN** с результатами выполнения).
* **`Диаграммы_БД_Автосервис.docx`** — Альбом графических моделей и схем проекта:
  - 1. Организационная структура автосервиса (`org_structure.png`).
  - 2. Модели процессов: IDEF0 блок А0 (`idef0_a0.png`) и DFD потоков данных (`dfd_order_flow.png`).
  - 3. Архитектура информационной системы и безопасность данных (`is_architecture.png`).
  - 4. Концептуальная ER-диаграмма на русском языке (`er_conceptual_ru.png`).
  - 5. Физическая реляционная схема базы данных СУБД SQLite 3 (`db_schema_physical_en.png`).
  - 6. Сравнительная таблица соответствия концептуального и физического уровней (PK/FK).
* **`autoservice.db`** — Рабочий бинарный файл базы данных SQLite 3:
  - 8 нормализованных таблиц (3НФ), 5 индексов, включенная ссылочная целостность (FK).
  - Наполнена реалистичными демонстрационными данными (клиенты, автомобили, заказы, запчасти).
  - Готова к открытию в **DB Browser for SQLite**, **DBeaver**, **VS Code** (расширение SQLite Viewer).
* **`queries.sql`** — Полный файл из 12 SQL-запросов (включая проверочный запрос без JOIN) с подробными комментариями на русском языке.
* **`schema.sql`** — DDL-скрипт создания таблиц, проверочных ограничений (CHECK, UNIQUE, NOT NULL) и B-Tree индексов.
* **`seed.sql`** — DML-скрипт наполнения базы данных демонстрационными данными.

---

### 2. Подкаталоги проекта:
* **`diagrams/`** — Все 6 графических диаграмм высокого разрешения (300 DPI):
  - `org_structure.png` — Схема оргструктуры предприятия.
  - `idef0_a0.png` — Контекстная диаграмма IDEF0 (блок А0).
  - `dfd_order_flow.png` — Диаграмма потоков данных DFD (уровень 1).
  - `is_architecture.png` — Архитектура ИС и терминалов.
  - `er_conceptual_ru.png` — Концептуальная ER-диаграмма.
  - `db_schema_physical_en.png` — Физическая схема РМД.
* **`scripts/`** — Вспомогательные Python-скрипты автоматизации:
  - `generate_diagrams.py` — Перегенерация всех схем в высоком разрешении.
  - `build_documents.py` — Сборка чистовых файлов Word (`.docx`) с форматированием 11 pt.
  - `test_queries.py` — Автоматический тест выполнения всех 12 запросов на реальной базе `autoservice.db`.
