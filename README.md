# Проект: База данных информационной системы автосервиса

Комплект материалов подготовлен в соответствии с требованиями учебного задания (3 стрелки преподавателя).

## Состав комплекта (Основные файлы для сдачи):

1. **`Анализ_Автосервис.docx`** — Документ анализа предметной области (Microsoft Word):
   - **Раздел 1**: Краткая характеристика организации автосервиса ООО «АвтоМастер-Сервис» (профиль, направления, оргструктура, цели автоматизации).
   - **Раздел 2**: Бизнес-процессы организации (пошаговый регламент обслуживания, жизненный цикл заказ-наряда, складской контур).
   - **Раздел 3**: Краткая характеристика разрабатываемой информационной системы «АвтоСервис-Экспресс» (модули, СУБД SQLite 3, принципы ACID).
   - **Раздел 4**: Сущности и атрибуты для базы данных ИС (детальная таблица по всем 8 сущностям с типами, ключами PK/FK и обоснованием 3НФ).
   - **Раздел 5**: Пользователи ИС и их запросы к БД (4 роли: Мастер-приемщик, Автомеханик, Кладовщик, Директор + 11 оформленных SQL-запросов).

2. **`Диаграммы_БД_Автосервис.docx`** — Документ с диаграммами (Microsoft Word):
   - **ER (концепт) (рус.)** — Концептуальная диаграмма на русском языке с экспликацией сущностей, ключевых атрибутов и кардинальности связей (1:N, N:M).
   - **Схема БД (РМД физич) (англ.)** — Физическая реляционная схема базы данных на английском языке (таблицы, типы данных SQLite, ключи `PK`/`FK`, правила `CASCADE`/`RESTRICT`, индексы).
   - Сравнительная таблица соответствия концептуального и физического уровней.
   - *Примечание:* Сами схемы высокого разрешения (300 DPI) также сохранены в файлах `er_conceptual_ru.png` и `db_schema_physical_en.png`.

3. **`autoservice.db`** — Рабочий бинарный файл базы данных SQLite 3:
   - Полная структура из 8 связанных таблиц в 3-й нормальной форме.
   - Наполнена реалистичными демонстрационными данными (клиенты, автомобили, сотрудники, услуги, склад запчастей, заказ-наряды).
   - Готова к открытию в любой программе: **DB Browser for SQLite**, **DBeaver**, **VS Code** (расширение SQLite Viewer).

## Вспомогательные файлы (для наглядности и запуска SQL):
- **`schema.sql`** — DDL-скрипт создания таблиц, ограничений и индексов.
- **`seed.sql`** — DML-скрипт наполнения базы данных демонстрационными данными.
- **`queries.sql`** — Все 11 SQL-запросов из Раздела 5 с подробными пояснениями на русском языке.
- **`build_database.py`** — Python-скрипт пересборки базы данных при необходимости.
